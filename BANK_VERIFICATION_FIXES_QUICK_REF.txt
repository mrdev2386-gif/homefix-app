---

## 📊 STATUS FLOW

```
pending/failed → verifying → verified ✅ (final)
                           → failed ❌ (can retry)
```

**Rules:**
- ✅ Can call function if: `pending`, `failed`
- ❌ Returns immediately if: `verified`
- ⏳ Never stuck in: `pending` or `verifying`

## 🔍 CHECK STATUS

```dart
final result = await FirebaseFunctions.instance
  .httpsCallable('checkBankVerificationStatus')
  .call();

bool canResubmit = result.data['canResubmit'];

String status = result.data['status'];
```
