🔧 TROUBLESHOOTING
==================

Q: Tests fail with "No mocks generated"
A: Run: flutter pub run build_runner build

Q: Tests timeout
A: Increase timeout: flutter test --timeout=30s

Q: Coverage report not generated
A: Install lcov: brew install lcov (macOS)

Q: Specific test fails
A: Run with verbose: flutter test -v test/file.dart
