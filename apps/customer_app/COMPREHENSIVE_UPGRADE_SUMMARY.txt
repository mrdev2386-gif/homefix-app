KEY IMPROVEMENTS
================

STREAM TESTING
--------------
BEFORE: expect(stream1, equals(stream2))
AFTER:  expect(identical(stream1, stream2), isTrue)

WEAK ASSERTIONS
---------------
BEFORE: expect(stream, isNotNull)
AFTER:  expect(stream, isA<Stream<List<Booking>>>())

EXCEPTION TESTING
-----------------
BEFORE: expect(() => fn(), throwsException)
AFTER:  expect(() => fn(), throwsA(isA<Exception>()))

MOCK SETUP
----------
BEFORE: class MockService extends Mock implements Service {}
AFTER:  @GenerateMocks([Service])

MOCK VERIFICATION
-----------------
BEFORE: No verification
AFTER:  verify(mock.method()).called(1)

STREAM EMISSION
---------------
BEFORE: expect(stream, isNotNull)
AFTER:  final result = await stream.first
         expect(result, isA<List>())
