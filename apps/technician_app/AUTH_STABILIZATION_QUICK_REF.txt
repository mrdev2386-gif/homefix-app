WHAT CHANGED?
=============

1. FIREBASE ID TOKEN REFRESH
   - Added before EVERY Cloud Function call
   - Prevents UNAUTHENTICATED errors
   - Ensures fresh tokens for secure operations

2. APP CHECK RETRY GUARD
   - Max 2 retry attempts (prevents "Too many attempts" errors)
   - 1 second delay between retries
   - Graceful failure - app continues even if token fails

3. AUTH STATE VALIDATION
   - User authentication checked before token refresh
   - Prevents null pointer exceptions
   - Detailed error messages

IF SOMETHING GOES WRONG
========================

SYMPTOM: Still getting UNAUTHENTICATED errors
  CHECK:
  1. Is user logged in? (Check AuthGate)
  2. Is token refresh being called? (Check logs)
  3. Is Cloud Function expecting auth? (Check backend)
  FIX:
  1. Ensure user is authenticated before operation
  2. Check that getIdToken(true) is called
  3. Verify Cloud Function has auth check

SYMPTOM: App Check token retrieval hanging
  CHECK:
  1. Are retries happening? (Check logs)
  2. Is delay between retries working? (Check timing)
  3. Is app continuing after failure? (Check UI)
  FIX:
  1. Verify retry guard is in place (max 2 attempts)
  2. Verify 1 second delay between retries
  3. Verify app doesn't crash on failure

SYMPTOM: Logs not showing token refresh
  CHECK:
  1. Is debugPrint() being called? (Check console)
  2. Is operation reaching Cloud Function? (Check logs)
  3. Is user authenticated? (Check auth state)
  FIX:
  1. Ensure debugPrint() is called before getIdToken()
  2. Add more logging to trace execution
  3. Verify user is logged in

CODE PATTERNS
==============

PATTERN 1: Token Refresh Before Cloud Function
  
  // CRITICAL: Ensure user is authenticated
  final user = FirebaseAuth.instance.currentUser;
  if (user == null) {
    throw Exception('User not authenticated');
  }
  
  // CRITICAL: Refresh Firebase ID token BEFORE calling Cloud Function
  debugPrint('[OPERATION] Refreshing Firebase ID token for uid=${user.uid}');
  await user.getIdToken(true);
  debugPrint('[OPERATION] Token refreshed successfully');
  
  // NOW call the Cloud Function with fresh token
  HttpsCallable callable = _functions.httpsCallable('functionName');
  final result = await callable.call(data);

PATTERN 2: App Check Retry Guard
  
  int retries = 0;
  const maxRetries = 2;
  
  while (retries < maxRetries) {
    try {
      debugPrint('[APP CHECK] Attempting to get App Check token (attempt ${retries + 1}/$maxRetries)');
      await FirebaseAppCheck.instance.getToken(true);
      debugPrint('[APP CHECK] Token retrieved successfully');
      return;
    } catch (e) {
      retries++;
      if (retries < maxRetries) {
        debugPrint('[APP CHECK] Token retrieval failed, retrying in 1 second...');
        await Future.delayed(const Duration(seconds: 1));
      } else {
        debugPrint('[APP CHECK] Token retrieval failed after $maxRetries attempts: $e');
        return; // Don't rethrow - allow app to continue
      }
    }
  }
