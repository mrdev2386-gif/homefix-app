## TROUBLESHOOTING

### Issue: Notification not received

**Check 1:** Is FCM token saved?
```bash
# In Firestore, check technicians/{id}/fcmTokens collection
# Should have at least one token document
```

**Check 2:** Is trigger deployed?
```bash
firebase functions:list | grep onTechnicianApproved
```

**Check 3:** Check logs for errors
```bash
firebase functions:log --only onTechnicianApproved
```

### Issue: Trigger not firing

**Check 1:** Is status field being updated?
```bash
# In Firestore, check technicians/{id}
# Should have status: "approved" after admin approval
```

**Check 2:** Is trigger watching correct field?
```bash
# In approval_notifications.ts, verify:
# if (before.status === 'approved' && after.status === 'approved')
```

### Issue: Notification sent but not displayed

**Check 1:** Is app in foreground?
- If app is in background, notification should appear in notification tray
- If app is in foreground, notification may not show (depends on Flutter config)

**Check 2:** Check device notification settings
- Ensure notifications are enabled for the app
- Check notification channel settings
