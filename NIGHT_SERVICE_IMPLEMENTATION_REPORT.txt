=== NIGHT SERVICE BOOKING LOGIC ===

Night Time Range: 10:00 PM (22:00) - 6:00 AM (06:00)

Behavior:
- If nightService.enabled == true:
  * Customer CAN book during night hours
  * Night charge applied automatically (if configured)
  * Night charge is optional (can be 0)

- If nightService.enabled == false:
  * Customer CANNOT book during night hours
  * Cloud Function throws error

Examples:
Case 1: Night enabled + nightCharge = 100
  Booking at 1 AM → finalPrice = basePrice + urgentFee (if urgent) + 100

Case 2: Night enabled + nightCharge = 0
  Booking at 1 AM → finalPrice = basePrice + urgentFee (if urgent)

Case 3: Night disabled
  Booking at 1 AM → Error: "Night service is not available"

=== CLOUD FUNCTION LOGIC ===

Input:
{
  serviceId: string,
  technicianId: string,
  bookingTime: string (ISO 8601),
  isUrgentBooking?: boolean
}

Processing:
1. Fetch service document
2. Calculate base price
3. If isUrgentBooking:
   - Verify urgentBooking.enabled == true
   - Add urgentFee to finalPrice
4. Detect night time from bookingTime:
   - hour = new Date(bookingTime).getHours()
   - isNightTime = hour >= 22 || hour < 6
5. If isNightTime:
   - Verify nightService.enabled == true
   - Add nightCharge to finalPrice (if > 0)
6. Return finalPrice + breakdown + isNightTime

Output:
{
  success: true,
  finalPrice: number,
  breakdown: {
    basePrice: number,
    urgentFee?: number,
    nightCharge?: number,
    finalPrice: number
  },
  isNightTime: boolean
}

Error Cases:
- Service not found → 404
- Urgent booking not enabled → 400
- Night service not enabled (during night) → 400
- Invalid fee configuration → 500
