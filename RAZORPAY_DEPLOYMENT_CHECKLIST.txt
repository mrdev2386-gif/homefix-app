TESTING SCENARIOS:
──────────────────

SCENARIO 1: Successful Payment
───────────────────────────────
1. Create booking → pending_admin_review
2. Admin approves → approved_by_admin
3. Technician accepts → technician_accepted
4. Technician starts service → service_in_progress
5. Technician completes service → awaiting_payment
6. Customer pays via Razorpay → paid
7. Technician wallet credited
8. Customer can rate service

Expected Results:
✓ Booking status = "paid"
✓ Payment status = "paid"
✓ Technician wallet balance increased
✓ Transaction logged in wallet_transactions
✓ Payment logged in payment_logs

────────────────────────────
1. Customer initiates payment
2. Payment fails in Razorpay
3. Error message shown
4. Retry button available
5. Customer retries payment

Expected Results:
✓ Booking status remains "awaiting_payment"
✓ Payment status remains "awaiting_payment"
✓ No wallet credit
✓ Error logged in payment_logs

SCENARIO 3: Duplicate Payment Attempt
──────────────────────────────────────
1. Customer pays successfully
2. Booking status = "paid"
3. Customer tries to pay again

Expected Results:
✓ Second payment rejected
✓ Wallet not credited twice
✓ Error message shown to customer
✓ Logged as duplicate attempt

ROLLBACK PLAN:
──────────────

If issues occur:

1. Revert Cloud Functions:
   git revert <commit-hash>
   firebase deploy --only functions

2. Revert Flutter App:
   git revert <commit-hash>
   flutter build apk --release

3. Check Firestore data:
   - Verify no orphaned payment records
   - Verify wallet balances are correct
   - Check payment_logs for issues

4. Manual fixes if needed:
   - Use admin panel to adjust wallet balances
   - Mark bookings as paid if needed
   - Create refund records if needed

TROUBLESHOOTING:
────────────────

Issue: Payment order creation fails
Solution:
- Check Razorpay credentials in Firebase config
- Verify booking exists and status = "awaiting_payment"
- Check Cloud Functions logs for errors
- Verify Razorpay API is accessible

Issue: Payment verification fails
Solution:
- Check signature verification logic
- Verify amount matches booking total
- Check booking status is "awaiting_payment"
- Verify Razorpay payment exists

Issue: Technician wallet not credited
Solution:
- Check wallet_transactions collection
- Verify transaction was created
- Check for errors in transaction
- Manually credit if needed

Issue: Duplicate payment detected
Solution:
- Check payment_logs for duplicate entries
- Verify transaction-safe check is working
- Check for race conditions
- Review logs for timing issues
