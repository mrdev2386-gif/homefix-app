ERROR HANDLING FLOW
═══════════════════════════════════════════════════════════════════════════════

onTechnicianApproved trigger
    │
    ├─ Try: Send FCM notification
    │   │
    │   ├─ Success: Log delivery stats
    │   │   └─ [NOTIFICATION] ✅ Notification sent
    │   │
    │   └─ Failure: Handle error
    │       │
    │       ├─ Invalid token: Delete token
    │       │   └─ [NOTIFICATION] ⚠️ Token deleted
    │       │
    │       ├─ Network error: Log error
    │       │   └─ [NOTIFICATION] ❌ Network error
    │       │
    │       └─ Other error: Log and continue
    │           └─ [NOTIFICATION] ❌ Error: {message}
    │
    └─ Finally: Don't fail function
        └─ Notification is best-effort
        └─ Approval still succeeds
