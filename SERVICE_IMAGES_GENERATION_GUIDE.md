# Service Images Generation Guide
## Professional Home Services App

### Overview
This guide provides optimized prompts for generating ultra-realistic service images for a home services mobile app (Urban Company-style).

---

## Global Image Specifications

### Technical Requirements
- **Resolution:** 1024×1024 pixels
- **Format:** JPG or PNG
- **Style:** Ultra-realistic photography
- **Camera:** DSLR / iPhone Pro portrait quality
- **Lighting:** Natural indoor lighting
- **Focus:** Sharp, professional

### Content Rules
- ✅ Real professional photography look
- ✅ Modern Indian home interiors
- ✅ Professional technician in neutral uniform
- ✅ Service-specific tools and equipment visible
- ✅ Clean, premium environment
- ❌ No text, logos, or watermarks
- ❌ No UI elements or app mockups
- ❌ No blur or distortion
- ❌ No illustrations or cartoons

## Image Generation Workflow

### Step 1: Choose Your AI Tool
**Recommended Tools:**
1. **Midjourney** (Best for photorealism)
   - Use `--style raw` for realistic photos
   - Use `--ar 1:1` for square format
   - Use `--v 6` for latest version

2. **DALL-E 3** (via ChatGPT Plus)
   - Specify "photorealistic" in prompt
   - Request "no text or watermarks"

3. **Leonardo.ai** (Good for batch generation)
   - Use "PhotoReal" model
   - Set to 1024x1024 resolution

4. **Stable Diffusion** (Open source)
   - Use realistic checkpoint models
   - Add negative prompts for unwanted elements

### Step 2: Generate Images
- Use the optimized prompts above
- Generate 2-3 variations per service
- Select the best one

### Step 3: Post-Processing (Optional)
- Remove any unwanted text/logos
- Adjust brightness/contrast if needed
- Crop to exact 1024x1024 if necessary
- Compress for mobile app use (keep under 500KB)

### Step 4: Quality Check
Verify each image has:
- ✅ Clear service identification
- ✅ Professional technician visible
- ✅ Relevant tools/equipment
- ✅ Clean, modern environment
- ✅ Natural, realistic lighting
- ✅ Sharp focus, no blur
- ✅ No text, logos, or watermarks

## Firebase Storage Upload

Once you have the images, upload them to Firebase Storage:

### Storage Structure
```
service_images/
  ├── ac_repair_service.jpg
  ├── electrician_service.jpg
  ├── plumber_service.jpg
  ├── house_cleaning_service.jpg
  ├── bathroom_cleaning_service.jpg
  ├── pest_control_service.jpg
  ├── appliance_repair_service.jpg
  ├── ro_water_purifier_service.jpg
  ├── painting_service.jpg
  └── carpenter_service.jpg
```

### Upload via Firebase Console
1. Go to Firebase Console → Storage
2. Create `service_images` folder
3. Upload each image with exact filename
4. Set public read access
5. Copy download URLs

### Update Firestore
Add image URLs to your services collection:

```javascript
services/ac_repair_service
{
  "imageUrl": "https://firebasestorage.googleapis.com/.../ac_repair_service.jpg",
  "title": "AC Repair & Service",
  "category": "appliance",
  // ... other fields
}
```

## Mobile App Integration

### Flutter Implementation
```dart
// In your service card widget
CachedNetworkImage(
  imageUrl: service.imageUrl,
  fit: BoxFit.cover,
  placeholder: (context, url) => CircularProgressIndicator(),
  errorWidget: (context, url, error) => Icon(Icons.error),
)
```

### Image Optimization
- Compress images to ~300-500KB each
- Use WebP format for better compression
- Implement lazy loading
- Cache images locally
