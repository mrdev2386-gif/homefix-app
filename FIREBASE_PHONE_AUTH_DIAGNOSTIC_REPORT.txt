occurs because:

1. CONFIGURATION MISMATCH:
   - google-services.json contains SHA-1 from RELEASE keystore
   - Debug build uses DEFAULT Android debug keystore (different SHA-1)
   - Firebase Console expects the configured SHA-1
   - App Check cannot verify the app identity

2. TIMING OF FAILURE:
   - Firebase initialization: ✓ SUCCESS
   - App Check activation: ✓ SUCCESS (uses debug provider in debug mode)
   - Phone Auth call: ✗ FAILS
   - Reason: Play Integrity API cannot verify app identity due to SHA mismatch

3. WHY IT HAPPENS:
   - When running `flutter run`, the app is signed with debug keystore
   - Debug keystore SHA-1 ≠ Release keystore SHA-1 (in google-services.json)
   - Firebase Phone Auth requires valid app identifier
   - App Check verification fails → Phone Auth fails

4. EVIDENCE:
   - File: android/app/build.gradle:45-54
   - Issue: Using fallback debug.keystore (key.properties not found)
