EMAIL VERIFICATION FIX FOR PHONE-AUTH USERS

=== PROBLEM ===

Phone-auth users don't have email attached to Firebase Auth.
When technician enters email and clicks "Verify Email", sendEmailVerification() fails.
Logs showed: email = (empty)

=== ROOT CAUSE ===

Phone authentication creates user without email.
Firebase requires email to be attached before sending verification.

=== SOLUTION IMPLEMENTED ===

File Modified: edit_personal_details_screen.dart

Method: _sendVerificationEmail()

STEP 1 — Attach email to Firebase user
```dart
final user = FirebaseAuth.instance.currentUser;
if (user == null) throw Exception('User not authenticated');

// Attach email if not already attached (for phone-auth users)
if (user.email == null || user.email!.isEmpty) {
  await user.updateEmail(email);
}
```

STEP 2 — Send verification email
```dart
await user.sendEmailVerification();
```

STEP 3 — Start auto-check timer
```dart
_startAutoCheckTimer(); // Polls every 5 seconds
```

=== VERIFICATION FLOW ===

1. Technician enters email in Personal Details
2. Taps "Verify Email"
3. updateEmail() attaches email to Firebase user
4. sendEmailVerification() sends verification link
5. Auto-check timer starts (5-second intervals)
6. Technician clicks email link in inbox
7. Returns to app
8. Auto-check detects emailVerified == true
9. Shows "✓ Email verified successfully!"
10. Can now save profile

=== CHECK VERIFICATION METHOD ===

Method: _checkVerificationStatus()

STEP 1 — Reload Firebase user
```dart
await FirebaseAuth.instance.currentUser?.reload();
```

STEP 2 — Check email verification status
```dart
final user = FirebaseAuth.instance.currentUser;
final isVerified = user.emailVerified;
```

STEP 3 — Update Firestore
```dart
if (isVerified) {
  await FirebaseFirestore.instance
      .collection('technicians')
      .doc(user.uid)
      .update({'emailVerified': true});
}
```
