PROBLEM:
- Firebase showed "Please reauthenticate to continue" error
- Happened when technician tried to verify email
- Caused by Firebase requiring recent login for sensitive actions

SOLUTION IMPLEMENTED:
✅ Use sendEmailVerification() directly on current user
✅ No reauthentication required
✅ Works with phone-auth users
✅ Auto-check verification status every 5 seconds

CODE CHANGES:
File: edit_personal_details_screen.dart

1. _sendVerificationEmail() method:
   - Calls user.sendEmailVerification() directly
   - No reauthentication logic
   - Starts auto-check timer after sending

2. _startAutoCheckTimer() method:
   - Polls verification status every 5 seconds
   - Stops when email verified
   - Silent polling (no error messages)

3. _checkVerificationStatus() method:
   - Reloads Firebase user
   - Checks emailVerified flag
   - Updates Firestore when verified
   - Shows success message

4. Auto-check starts (every 5 seconds)
